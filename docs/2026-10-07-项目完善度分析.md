## 三、发现的问题（按严重度排序）

### 🐛 P0-1　Reflection C2「数值一致性」检查完全失效（破坏核心不变式 #5）

**位置**：`nodes/reflect_node.py:163`

```python
found = re.findall(rf"{re.escape(s_['name'])}[^\n]{{0,40}}?(\d{1,3}(?:\.\d)?)\s*分", draft)
```

f-string 里 `{{0,40}}` 做了转义（正确），但 `(\d{1,3}...)` 的 `{1,3}` **没有转义**。
Python 会把 `{1,3}` 当成**替换表达式**求值 → 变成元组 `(1, 3)`，最终正则是 `\d(1, 3)`，
对任何「两位及以上分数」都匹配不到。

**后果**：CLAUDE.md 核心不变式 #5「reflect_node 的 C2 即使 LLM 说 accept 也强制 revise」
实际从未对多位数分数生效。目前靠 `answer_node::_sanitize()` 的输出侧兜底（那段正则是对的）
才没出事故，等于**少了一道防线**。

**为何测试没抓到**：`test_reflection_guard_no_hallimination` 验证的是「最终答案与评分一致」，
而答案本来就由确定性模板渲染，天然一致——它测不到「C2 能否发现不一致」。

---

### ⚠️ P1-1　`job_recommend` 意图端到端不通

**现象**（实测）：

- 「给张伟推荐岗位」→ 正确识别为 `job_recommend`，但**产出 0 条结果**，答案退化为
  「已完成处理，但未产出可展示的结论」。
- 「给张伟推荐几个合适的岗位」→ 误判为 `chitchat`。
- 「张伟能投哪些岗位 / 有什么适合张伟的岗位」→ 误判为 `policy_qa`。

**根因**（两层）：

1. **检索层**：`retrieve_node` 固定检索 `COLLECTION_CANDIDATES`，`score_node` 固定给
   候选人打分。`job_recommend` 需要的是「**对岗位打分**」，但岗位根本没进向量库
   （`index_data.py` 只索引候选人与知识库），`list_jobs` 的结果也没有喂给评分链路。
   → 走到 `score_node` 时候选池为空 → shortlist 为空 → 答案走 fallback 分支。
2. **意图层**：`_RULES` 里 `job_recommend` 的触发词只有
   `["推荐岗位","适合的岗位","有什么岗位","匹配岗位","适合他"]`，
   自然语句「推荐几个合适的岗位 / 适合张伟的岗位」命不中，被其它规则抢走。

**影响**：README/CLAUDE.md 宣称支持 8 个意图，实际只有 7 个可用。

### ⚠️ P2-1　Rerank 面试完成度加分是死分支

**位置**：`rag/rerank.py:97`

```python
iv = md.get("interview") or {}
if isinstance(iv, dict) and iv.get("score"):
    bonus += 0.1 * min(1.0, float(iv["score"]) / 100)
```

候选人 chunk 的 metadata 里**没有 `interview` 键**，只有 `interview_score` / `interview_rounds`
（见 `index_data.py::build_candidate_chunks`）。实测 `md.get("interview")` 恒为 `None`，
这段面试加分**永远不执行**。排序少了一个本应生效的业务信号。

---

### ⚠️ P2-2　ElasticsearchStore 客户端初始化类型错误

**位置**：`vectorstore/es_store.py:36`

```python
kwargs: dict[str, Any] = [s.es_url]        # 标注 dict，实际是 list
...
self._es = Elasticsearch(*kwargs, **client_kwargs)
```

靠 `*kwargs` 解包成位置参数**侥幸能跑**，但类型标注与实现矛盾，可读性差、易被后人改坏。
由于开发环境无 ES，这条路径从未被真实执行过。

### ℹ️ P3　其它观察（非 bug，属取舍或待办）

- **无鉴权 / 无状态 / 无持久化**：`api.py` 无认证，`RecruitAgent` 无 checkpointer，内存后端重启即丢。已在 README「已知限制」声明。

- **评测集偏窄**：10 条用例未覆盖 `job_recommend`、未覆盖 Reflection C2/C3 的「能否发现错误」。
